# Bagázs Karácsony 2026 - kiadások

A **Bagázs Karácsony 2026** WordPress plugin nyilvános kiadási csatornája.
A plugin ezt a tárolót ellenőrzi, és az új verziókat rendes frissítésként kínálja fel a WordPressben
(*Bővítmények* / *Irányítópult → Frissítések*).

A kiadások automatikusan készülnek a (privát) forrás tárolóból - ide kézzel ne commitolj.

Kézi telepítés: töltsd le a `bagazs-karacsony-2026.zip` fájlt a legfrissebb
[kiadásból](../../releases/latest), és töltsd fel a *Bővítmények → Új hozzáadása → Feltöltés* oldalon.
